# Corpus

Every image here is a lossless source, since images that were once JPEGs skew comparisons against JPEG encoders. Textures and mode images are 1024 crops scaled to 512 in linear light, and HDRIs are scaled to 1024x512, so the corpus downloads and measures quickly.
